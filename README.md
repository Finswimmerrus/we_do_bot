# Вместе

Telegram-бот и Mini App для общего списка задач пары. Для запуска достаточно Node.js 24 и SQLite, встроенной в Node.js.

## Запуск

1. Скопируйте `.env.example` в `.env` и укажите токен в `BOT_TOKEN`.
2. Выполните `npm start`. Бот принимает обновления через long polling. Запускайте один экземпляр на токен. Порт Mini App по умолчанию доступен локально на `127.0.0.1:3000`.
3. Отправьте боту `/start` в личном чате и перешлите показанную ссылку партнёру. Чтобы подключить общий чат, добавьте туда бота и отправьте `/link@имя_бота` как участник пространства. Ответы бота видны участникам общего чата. Отключить чат можно командой `/unlink` в личном чате.

Если у приглашённого уже есть одиночное пространство, бот предложит перенести его задачи и категории в пространство пары или остаться в своём. После подтверждения прежний общий чат приглашённого отключается. Пользователь, у которого уже есть партнёр, остаётся в своей паре.

Для Mini App подключите публичный HTTPS-адрес, проксирующий запросы на указанный порт. Укажите этот адрес в `MINI_APP_URL`, перезапустите сервис и снова отправьте `/start`. В личном чате появится кнопка **Открыть Mini App**. При открытии из Telegram сервер проверяет подпись Telegram и членство в пространстве. [Документация Telegram Mini Apps](https://core.telegram.org/bots/webapps#validating-data-received-via-the-mini-app).

Для постоянной работы запустите процесс как службу с автоматическим перезапуском. Сохраните каталог базы между перезапусками и храните токен в настройках службы или в закрытом файле `.env`.

## Команды

| Команда | Действие |
| --- | --- |
| `/task Купить билеты` | Создать активную задачу |
| `/backlog`, `/backlog без месяца`, `/backlog октябрь 2026` | Посмотреть бэклог и выбрать статус |
| `/month`, `/month 10 2026` | Посмотреть месяц и статистику |
| `/year`, `/year 2026` | Посмотреть итог года и перейти к задачам месяца |
| `/review`, `/review октябрь`, `/review year 2026` | Перенести, завершить, закрыть или пропустить активные задачи |
| `/invite` | Получить одноразовую ссылку для второго участника |

Для месяца без года бот выбирает текущий месяц, предыдущий календарный месяц или ближайшее будущее наступление указанного месяца. Часовой пояс задаётся через `TIME_ZONE`. Навигация по кнопкам сохраняет точный период.

В Mini App вкладка **Периоды** показывает задачи выбранного месяца или года с фильтрами. Итоги и разбор доступны во вкладке **Статистика**. Доля выполненных считается среди активных и выполненных.

При создании подзадачи категория по умолчанию берётся у родителя. После создания у каждой задачи свои категория, период, статус и важность. Глобальная важность доступна задачам верхнего уровня. Неактуальные задачи можно вернуть в активные.

При завершении родителя с открытыми подзадачами приложение спрашивает, продолжить ли. Карточка каждой подзадачи позволяет завершить её, сделать самостоятельной или удалить после подтверждения.

Категории общие для пары. Новое название, сохранённое в карточке задачи, появляется в выпадающем списке у обоих. В разделе **Пространство → Категории** можно добавить категорию, выбрать иконку и цвет или убрать категорию из задач пары.

При включённом распознавании отправьте голосовое в личный чат с ботом. Текст делится на отдельные задачи, которые сразу попадают в общий бэклог. Бот отвечает списком добавленных задач. Одна запись может длиться до 90 секунд и содержать до 15 задач. Голосовые из общего чата пропускаются.

Чтобы включить распознавание, запустите Whisper с многоязычной моделью и параметрами `--language ru` и `--convert`. Впишите его внутренний адрес с путём `/inference` в переменную `VOICE_TRANSCRIBER_URL`. Для голосовых Telegram сервису нужен `ffmpeg`. Ограничьте доступ к нему сетью приложения. [Документация whisper-server](https://github.com/ggml-org/whisper.cpp/tree/master/examples/server)

## База и проверка

- База хранится в `DATABASE_PATH`. Путь по умолчанию — `data/we-do.sqlite`.
- `npm run backup -- /путь/we-do-2026-11.sqlite` создаёт согласованную копию SQLite во время работы сервиса. Для восстановления остановите сервис и укажите путь к копии в `DATABASE_PATH`.
- `npm test` проверяет сценарии бота, хранения данных и Mini App локально с тестовыми аккаунтами.
